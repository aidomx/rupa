12345678910111213
// pattern matching with case
case status => {
    200: print("success")
    404: print("not found")
    500: print("server error")
    *: print("unknown")
}

// struct definition
People { name: string age: number }

// conditional assignment
result ?= valid -> "Success"
result ?= valid -> primary | fallback | "Unavailable"

Why Rupa

Versatile

Designed to grow across different contexts — from small experiments to larger systems.

Lightweight

No unnecessary complexity. Built with a minimal core that stays out of your way.

Flexible

Syntax adapts to your needs with async/await, pattern matching, and type annotations.

Solid Foundation

Feature changes never compromise the core structure without clear reasoning.

Built-in GC

Automatic memory management through a centralised garbage collector with clear ownership.

Native Async

First-class async/await with handlers, timeouts, and status tracking built into the language.
