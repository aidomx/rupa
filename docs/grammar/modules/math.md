# Math Module Grammar

Module `math` diimpor sebagai object module:

```rupa
import math from rupa
```

Daftar member native:

```text
math.abs(value)
math.sqrt(value)
math.pow(base, exponent)
math.floor(value)
math.ceil(value)
math.round(value)
math.sin(value)
math.cos(value)
math.tan(value)
```

Setiap pemanggilan terdiri dari member expression (`math.nama`) dan call
expression dengan jumlah argumen sesuai tabel API syntax.
