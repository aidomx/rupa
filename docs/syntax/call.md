# Call

## Apa yang bisa ditulis?

```rupa
add(1, 2)
print(add(1, 2), [3, 4])
```

## Kapan digunakan?

Gunakan call ketika ingin menjalankan function atau construct yang menerima argument.

## Apa hasilnya?

Argument dipisahkan dengan koma dan masing-masing dapat berupa expression, sehingga call dapat digunakan di dalam construct lain.
