# Syntax Basics

## Apa yang bisa ditulis?

```rupa
# Comment
x = 1
name = "rupa"
```

## Kapan digunakan?

Gunakan syntax dasar untuk menulis program Rupa. Setiap statement berada di baris baru.

## Apa hasilnya?

Rupa menggunakan syntax yang familiar dan readable. Setiap construct memiliki aturan yang konsisten.

### Contoh execution

```rupa
# This is a comment
x = 1
y = 2
print(x + y)
```

Output: `3`
