# Break dan Continue

## Apa yang bisa ditulis?

```rupa
break
continue
```

Contoh:

```rupa
for i < 10 {
    if i == 1: continue
    if i == 8: break
    print(i)
}
```

## Kapan digunakan?

Gunakan `continue` untuk melewati iterasi saat ini dan `break` untuk menghentikan loop.

## Apa hasilnya?

Keduanya adalah control statement tanpa value tambahan pada statement yang sama.
