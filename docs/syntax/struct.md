# Struct

## Apa yang bisa ditulis?

```rupa
People {
    name: string
    age: number
}
```

## Kapan digunakan?

Gunakan struct/blueprint untuk mendefinisikan bentuk dengan nama dan field. Rupa saat ini menggunakan nama construct langsung diikuti block, tanpa keyword `struct`.

## Apa hasilnya?

Block berisi field yang ditulis sebagai annotation. Struct dapat kemudian menjadi type yang dirujuk oleh annotation lain.
