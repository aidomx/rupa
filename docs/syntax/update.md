# Update

## Apa yang bisa ditulis?

```rupa
x++
x--
x += 5
x -= 3
```

## Kapan digunakan?

Gunakan update operator untuk mengubah value variable secara incrementally.

## Apa hasilnya?

Update operator memodifikasi value variable dan menghasilkan value baru.

### Contoh execution

```rupa
x = 10
x++
print(x)
```

Output: `11`

```rupa
x = 10
x--
print(x)
```

Output: `9`

```rupa
x = 10
x += 5
print(x)
```

Output: `15`

```rupa
x = 10
x -= 3
print(x)
```

Output: `7`
