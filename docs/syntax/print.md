# Print

## Apa yang bisa ditulis?

```rupa
print("hello world")
print(name)
print("x =", x)
print("result:", x + y, true)
print(add(1, 2), [3, 4])
```

## Kapan digunakan?

Gunakan `print` untuk menghasilkan output dari satu atau beberapa expression.

## Apa hasilnya?

Setiap argument dipisahkan dengan koma dan dievaluasi sebagai expression. Argument dapat berupa identifier, literal, binary expression, call, atau array.
