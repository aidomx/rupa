# Expression

## Apa yang bisa ditulis?

```rupa
1 + 2
10 * 5
100 / 4
2 + 3 * 4
10 % 3
```

String expression:

```rupa
"hello" + " " + "world"
```

## Kapan digunakan?

Expression adalah kombinasi value, operator, dan function calls yang menghasilkan value. Expression dapat digunakan di mana saja value diharapkan.

## Apa hasilnya?

Expression dievaluasi sesuai operator precedence. Hasilnya adalah value yang dapat digunakan atau ditampilkan.

### Contoh execution

```rupa
x = 1 + 2
print(x)
```

Output: `3`

```rupa
y = 10 * 5
print(y)
```

Output: `50`

```rupa
z = 100 / 4
print(z)
```

Output: `25`

```rupa
w = 2 + 3 * 4
print(w)
```

Output: `14`

```rupa
m = 10 % 3
print(m)
```

Output: `1`

```rupa
s = "hello" + " " + "world"
print(s)
```

Output: `hello world`
