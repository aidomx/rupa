# Literal

## Apa yang bisa ditulis?

```rupa
42
3.14
"hello"
true
false
null
```

## Kapan digunakan?

Literal adalah nilai konstan yang ditulis langsung dalam kode. Setiap literal memiliki tipe data yang sesuai.

## Apa hasilnya?

Literal langsung menghasilkan value sesuai tipenya.

### Contoh execution

```rupa
print(42)
```

Output: `42`

```rupa
print(3.14)
```

Output: `3.14`

```rupa
print("hello")
```

Output: `hello`

```rupa
print(true)
```

Output: `true`

```rupa
print(false)
```

Output: `false`
