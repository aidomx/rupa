# Design rupa language

Design _rupa_ hanya digunakan untuk membuat, menambahkan, mengubah, menghapus bagian-bagian tertentu dari bahasa _rupa_.

Semua file hasil design tidak ada yang dipublish keluar hanya digunakan untuk kebutuhan internal.

Jika beberapa mencantumkan rujukan ke `design/*.txt` dan tidak dapat menemukan filenya, itu sangat wajar dan harap perlu dimengerti.
